# Personal Finance Dashboard (Power BI)

## 🔗 Project Link
https://github.com/Bitu-Singh-Rathoud/finance-dashboard-powerbi

## 📌 Overview
This project presents an interactive Power BI dashboard for analyzing personal financial data. It provides insights into income, expenses, savings, and spending patterns using data visualization techniques.

## 🚀 Features
- Interactive dashboard with filters and slicers
- KPI tracking (Total Income, Expenses, Savings)
- Category-wise expense analysis
- Monthly trend visualization
- Data cleaning and transformation using Power Query

## 🛠 Tech Stack
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization

## 📊 Results
- Clear insights into spending habits and savings trends
- Improved financial decision-making using visual analytics
- Dynamic dashboard for real-time interaction

## ▶️ How to Use
1. Download the `.pbix` file
2. Open in Power BI Desktop
3. Interact with filters and visuals
